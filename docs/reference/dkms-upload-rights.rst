DKMS upload rights
##################

The `Ubuntu Kernel DKMS Uploaders team <https://launchpad.net/~ubuntu-kernel-dkms-uploaders>`__
maintains the :code:`kernel-dkms` package set, which provides out-of-tree kernel modules.

For information about the team and gaining upload rights see: :doc:`ubuntu-project-docs:who-makes-ubuntu/developers/dkms-uploaders`
