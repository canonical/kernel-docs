# How to obtain kernel source

There are two main ways to get a copy of the source code for an Ubuntu kernel.

```{toctree}
:titlesonly:
:maxdepth: 1
:hidden:

Obtain kernel source for an Ubuntu release using Git </how-to/source-code/obtain-kernel-source-git>
Obtain kernel source for an Ubuntu release from the archive </how-to/source-code/obtain-kernel-source-archive>
```

For a plain source tarball of a released version of
the kernel, [use this guide to get source from the
archive](/how-to/source-code/obtain-kernel-source-archive).

For a source tree with git history and potentially unreleased patches, [use this
guide to get source with git](/how-to/source-code/obtain-kernel-source-git).
